# 🎉 לוח שמחות - Backend

שרת API ללוח שמחות קבוצתי: משפחות וקבוצות חברים משתפות שמחות (חתונות, בריתות, בר מצוות ועוד), רואות לוח מסודר עם תאריך עברי ולועזי, ומקבלות תזכורת במייל ביום השמחה.

## טכנולוגיות

Node.js 20+ · Express 5 · TypeScript (strict) · PostgreSQL · Prisma ORM · Zod · JWT · bcrypt · Swagger / OpenAPI 3 · Vitest + Supertest

הלוח העברי (המרת תאריכים, שנים מעוברות, כתיב עברי) ממומש בקוד עצמו, בלי ספרייה או שירות חיצוני.
אין תלות בשירות AI או בשירות בתשלום. התזכורות במייל משתמשות במסלול החינמי של Brevo, והן לא חובה.

## מבנה הפרויקט

```
backend-project/
├── prisma/
│   ├── schema.prisma          # הגדרת הטבלאות
│   └── migrations/            # קובצי SQL שיוצרים את הטבלאות
├── src/
│   ├── server.ts              # נקודת הכניסה - מפעיל את השרת
│   ├── app.ts                 # הרכבת האפליקציה: middleware, נתיבים, Swagger
│   ├── config/env.ts          # קריאה ובדיקה של משתני הסביבה
│   ├── db/prisma.ts           # החיבור למסד הנתונים
│   ├── auth/                  # Authentication + Authorization
│   │   ├── tokens.ts          #   יצירה ואימות של JWT
│   │   ├── passwords.ts       #   Hash לסיסמאות (bcrypt)
│   │   ├── auth-user.ts       #   המשתמש המחובר בבקשה
│   │   └── permissions.ts     #   בדיקות הרשאה: חבר, מנהל, בעלים
│   ├── middleware/            # authenticate, טיפול בשגיאות, הגבלת ניסיונות, העלאת קבצים
│   ├── validation/            # הגדרות Zod והודעות שגיאה בעברית
│   ├── modules/               # כל נושא בתיקייה משלו
│   │   ├── auth/              #   *.routes.ts → *.controller.ts → *.service.ts + *.schemas.ts
│   │   ├── groups/
│   │   ├── celebrations/
│   │   ├── calendar/          #   כתובות עזר ללוח העברי
│   │   ├── reminders/         #   תזכורות במייל
│   │   └── meta/              #   בדיקת בריאות, סוגי שמחות
│   ├── services/email.ts      # שליחת מיילים דרך Brevo
│   ├── lib/                   # כלים: לוח עברי, תאריכים, שגיאות, זיהוי תמונות
│   ├── constants/             # סוגי השמחות ושמותיהם
│   ├── docs/openapi.ts        # תיעוד Swagger
│   └── seed/seed.ts           # נתוני הדגמה
├── tests/                     # בדיקות אוטומטיות (מול PostgreSQL אמיתי)
├── scripts/export-openapi.ts  # יצירת docs/openapi.json
├── docs/                      # אפיון + קובץ OpenAPI
├── render.yaml                # הגדרות פריסה ל-Render
└── .env.example               # דוגמה למשתני הסביבה
```

**איך עוברת בקשה:** `routes` (איזו כתובת) ← `authenticate` (מי המשתמש, לפי ה־Token) ← `controller` (בדיקת הקלט עם Zod) ← `service` (הרשאות + לוגיקה + מסד נתונים) ← תשובה. כל שגיאה מגיעה ל־`middleware/error-handler.ts` וחוזרת במבנה אחיד.

## הרצה מקומית (במחשב שלך)

**צריך:** Node.js 20 ומעלה (https://nodejs.org), ומסד נתונים PostgreSQL - מותקן במחשב, או מסד חינמי ב־Neon (ראו START-HERE.md, חלק ב).

```bash
# 1. התקנת הספריות
npm install

# 2. הגדרות: העתיקו את .env.example ל-.env ומלאו את DATABASE_URL, DIRECT_URL ו-JWT_SECRET
cp .env.example .env

# 3. יצירת הטבלאות במסד הנתונים
npm run db:deploy

# 4. נתוני הדגמה (סיסמה לכל המשתמשים: Demo1234)
npm run db:seed

# 5. הפעלת השרת (מתעדכן אוטומטית כשמשנים קוד)
npm run dev
```

פתחו את http://localhost:3000/api-docs 🎉

## בדיקות אוטומטיות

הבדיקות רצות מול **מסד PostgreSQL אמיתי ונפרד** - לא מסד הפיתוח, כי הבדיקות מרוקנות את הטבלאות בין בדיקה לבדיקה.

```bash
# 1. צרו מסד נתונים ריק לבדיקות (פעם אחת). מטעמי בטיחות, השם חייב להכיל "test"
createdb semachot_test

# 2. הריצו
export TEST_DATABASE_URL="postgresql://postgres:postgres@localhost:5432/semachot_test?schema=public"
npm test
```

לפני הבדיקות מוחלים קובצי ה־Migrations על המסד (`prisma migrate deploy`), כך שגם הם נבדקים.

**תוצאות ההרצה האחרונה: 119 מתוך 119 בדיקות עברו.** פירוט מלא ב־[docs/VERIFICATION.md](docs/VERIFICATION.md).

**מה נבדק:**
- **התחברות:** הרשמה, Login תקין ושגוי, Token חסר / לא תקין / חתום במפתח אחר / שפג תוקפו, משתמש שנמחק, סיסמה נשמרת כ־Hash ולא נחשפת.
- **הרשאות:** מנהל מול חבר מול מי שאינו חבר (403 / 404) בכל פעולה, הסרת חברים, יציאה (כולל העברת ניהול ומחיקת קבוצה ריקה), קוד הצטרפות חדש מבטל את הישן.
- **שמחות:** הוספה עם תאריך עברי ולועזי, תאריכים שלא קיימים, ולידציה, עריכה ומחיקה, מניעת גישה לשמחות של קבוצות אחרות, הסרה מקבוצה.
- **חיפוש, סינון ומיון:** לפי קבוצה, סוג, זמן, חודש עברי, טקסט חופשי, "שלי", מיון ועמודים.
- **תמונות:** העלאה, הצגה, החלפה, מחיקה, קובץ שמתחזה לתמונה (415), קובץ גדול (413).
- **לוח עברי:** תאריכים ידועים (ראש השנה, חגים), שנים מעוברות, המרה הלוך וחזור לכל יום ב־35 שנה, כתיב עברי.
- **תזכורות:** מייל אחד לאדם, רק למי שהתזכורות שלו דולקות, בלי כפילויות בהפעלה חוזרת.
- **Swagger:** כל הכתובות מתועדות, כל הפרטיות מסומנות כדורשות Token, כל ההפניות תקינות.

## אבטחה - בקצרה

- סיסמאות נשמרות כ־Hash של bcrypt ולעולם לא מוחזרות.
- JWT בתוקף מוגבל (ברירת מחדל: יום), הסוד במשתנה סביבה בלבד.
- המשתמש מזוהה **רק** לפי ה־Token - לא לפי מזהה שנשלח מהדפדפן.
- כל בדיקות ההרשאה בצד השרת. מי שאינו חבר בקבוצה מקבל 404 - כדי שלא יוכל לגלות שהיא קיימת.
- כל קלט נבדק עם Zod. שדות לא מוכרים נדחים.
- הגבלת ניסיונות התחברות והרשמה (20 ב־15 דקות).
- תמונות נבדקות לפי התוכן האמיתי של הקובץ, לא לפי הסיומת. הכתובת שלהן כוללת מזהה אקראי של 192 ביט.
- CORS לפי רשימת כתובות מוגדרת. כותרות אבטחה עם Helmet.
