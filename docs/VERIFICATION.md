## ✅ סימולציה של פריסה ל־Render
הורצו בדיוק הפקודות של ה־Build ב־Render, על מסד נתונים חדש, עם `NODE_ENV=production`:
- `prisma migrate deploy` ← הטבלאות נוצרו.
- Seed בלי `SEED_DEMO_DATA` ← דילג (כמתוכנן). עם הדגל אבל בלי סיסמה ← דילג (כמתוכנן). עם סיסמה ← נוצרו 3 משתמשים, 3 קבוצות ו־8 שמחות. הרצה חוזרת ← לא יצרה כפילויות.
- `npm start` ← השרת עלה, ונבדקו בקשות HTTP אמיתיות:

| בקשה | תוצאה |
|---|---|
| `GET /api/health` | `{"status":"ok","database":"ok"}` |
| `GET /api-docs` | 200. נבדק בדפדפן: כפתור Authorize מוצג, 30 פעולות |
| `GET /api/groups` בלי Token | 401 |
| Login עם סיסמת ההדגמה של פיתוח (Demo1234) בענן | 401 - כמתוכנן, בענן הסיסמה שונה |
| חבר רגיל מנסה לשנות שם קבוצה | 403 |
| הוספת שמחה עם כ״ה בכסלו תשפ״ז | נשמרה עם התאריך הלועזי 2026-12-05, ונשלפה בהצלחה על ידי חברה אחרת בקבוצה |
| העלאת תמונה והצגתה | 200, `image/png` |
| CORS מכתובת מורשית / לא מורשית | מאושר / נחסם |
| חיפוש "משה" | החזיר את "חתונת אחי משה" |
| תזכורות בלי שירות מייל | `emailEnabled: false`, השרת ממשיך לעבוד |

## ⚠️ מה לא נבדק
- **שליחת מייל אמיתית דרך Brevo** - דורשת חשבון ומפתח שלך. הקוד של בניית המייל והלוגיקה של מי מקבל נבדקו, אבל לא החיבור ל־Brevo עצמו.
- **הפריסה עצמה ב־Render וב־Neon** - דורשת את החשבונות שלך. הפקודות נבדקו בסימולציה מקומית.

## שינויים שבוצעו בעקבות הבדיקות
1. תיקון טיפוס בשמירת תמונה (Buffer → Uint8Array) - שגיאת TypeScript.
2. תיקון בדיקה שהשתמשה בשם קבוצה באורך תו אחד (השרת דחה אותו בצדק).
3. שדרוג Zod 3 → 4 ו־Vitest 3 → 5 בגלל פגיעויות אבטחה שדווחו בגרסאות הישנות.
4. נעילת `deepmerge-ts` לגרסה מתוקנת (בתוך Prisma CLI).
5. הבדיקות מחילות Migrations עם `migrate deploy` (שאינו מוחק נתונים) במקום `migrate reset`.
6. הצגת טקסטים עבריים מימין לשמאל ב־Swagger.
